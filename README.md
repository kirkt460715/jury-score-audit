# 文创盲评业务交接

作品用匿名号贯穿各次评分，申报与评分由独立人员提供。初评桥接证据和后续匿名分数均可查阅。 数据全部为合成业务记录。文件使用 UTF-8 JSON，时间均为北京时间，货币如无单独说明均为人民币分。

## 查阅交接数据

使用 Python 3.11 标准库。在仓库根目录运行 `python3 inspect_delivery.py` 查看交接文件和行数，或在后面加文件名（含 `.json`）查看该文件的第一条记录。这个入口仅供查阅交接资料。

## 数据约定

- `entries.json` P 对应专业组、S 对应高校组，mentor 是只供回避核查的匿名指导关系标识。未在某时段候选清单取得评分不能算零分。
- `ratings.json` 原始匿名分数在 0 到 100 分之间，轮次和入账时间独立。初评桥接评委用同一评分尺跨组评价，具有回避效力的申报按适用作品排除。复审可以重复评价同一作品，但要能识别是哪轮证据。
- `conflicts.json` scope 为 work 或 mentor，instead_of 指回避作品或导师号。listed_on 为秘书处收到并确认回避的时间。
- `slots.json` 同一时段的评委可承担 seats 件合格作品，资质须覆盖作品类别。席位数按给定可用时段计算。
- `award_policy.json` 每组各奖名额和依次比较的优先级，星号跨两组，共推奖先占作品资格。
- `comparison_policy.json` 认定可比至少需要的有效评次及不同来源评分团间可用的共同作品数。校准后的现有证据若不能解除指定分差以内的并列，不能仅按匿名号取得奖名。
- `decisions.json` 已经发过的确认记录，用于读取当时对外作出的承诺。

## 检查资料

运行 `python3 -m unittest discover -s tests -v`。检查会读取当前交接文件，核对该业务所需的关键原始证据是否齐备。
